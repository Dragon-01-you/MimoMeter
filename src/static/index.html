使用指南

3 分钟开始使用 MiMo Meter

快速开始
1
下载并运行
下载 MimoMeter.exe，双击运行。会自动打开浏览器仪表盘。
下载地址: https://github.com/Dragon-01-you/MimoMeter/releases
2
获取 API Key
登录 MiMo Token Plan 控制台，复制你的 API Key。
控制台: https://token-plan-cn.xiaomimimo.com
3
修改 API 地址
在你的代码中，把 API 地址改成 MiMo Meter 的代理地址。
# 原来
base_url = "https://token-plan-cn.xiaomimimo.com/v1"

# 改成
base_url = "http://127.0.0.1:8080/v1"
4
正常调用
其他代码不用改，正常使用即可。用量会自动记录到仪表盘。
# Python 示例 (OpenAI 格式)
from openai import OpenAI

client = OpenAI(
  base_url="http://127.0.0.1:8080/v1",
  api_key="你的 API Key"
)

response = client.chat.completions.create(
  model="mimo-v2.5-pro",
  messages=[{"role": "user", "content": "你好"}]
)
