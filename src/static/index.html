设置 API

填写你的 MiMo Token Plan API Key 并测试连接

API Key 配置
从 MiMo Token Plan 控制台获取你的 API Key
格式类似: tp-xxxxxxxxxxxx
如何获取 API Key
按照以下步骤获取你的 API Key
1. 打开 MiMo Token Plan 控制台
https://token-plan-cn.xiaomimimo.com

2. 登录你的小米账号

3. 在控制台找到 API Key
4. 复制 Key，粘贴到上方输入框
配置完成后
在你的代码中修改 API 地址
from openai import OpenAI

client = OpenAI(
  base_url="http://127.0.0.1:8080/v1",
  api_key="你的 API Key"
)
from anthropic import Anthropic

client = Anthropic(
  base_url="http://127.0.0.1:8080/anthropic",
  api_key="你的 API Key"
)

使用指南

完整的安装和使用教程

快速开始 (3 分钟)
第 1 步: 下载运行
下载 MimoMeter.exe，双击运行
浏览器会自动打开仪表盘

第 2 步: 填写 API Key
点击顶部「设置 API」按钮
粘贴你的 API Key
点击「测试连接」验证

第 3 步: 修改代码
把 API 地址改成:
OpenAI 格式: http://127.0.0.1:8080/v1
Anthropic 格式: http://127.0.0.1:8080/anthropic

第 4 步: 正常使用
其他代码不用改，正常调用即可
用量会自动记录到仪表盘
支持的工具
Python (openai 库)
base_url = "http://127.0.0.1:8080/v1"

Python (anthropic 库)
base_url = "http://127.0.0.1:8080/anthropic"

Cursor / VS Code
设置 → OpenAI Base URL → http://127.0.0.1:8080/v1

Claude Code / Claude Desktop
设置 → Anthropic Base URL → http://127.0.0.1:8080/anthropic
macOS / Linux 用户
